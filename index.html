Step 1

Create a GitHub Account

GitHub is where your website will live. It's free and you'll keep this account after the workshop.

Already have a GitHub account? Skip to Step 2 →

  1. 1
    Go to github.com

    Click Sign up in the top-right corner.

  2. 2
    Enter your email address

    Any email address works fine.

  3. 3
    Choose a username carefully

    This becomes your website URL: your-user-name.github.io. Your username will be public — anyone who visits your site will see it — so pick something you're happy to share.

  4. 4
    Verify your email

    GitHub sends a confirmation link. Click it to activate your account.

  5. ✓
    You have a GitHub account!

    Leave this browser tab open — you'll need it again in Step 5.

Step 2

Install Claude Code

Claude Code is a command-line AI assistant that reads and writes code alongside you. It runs in your terminal.

First: open your terminal

How to open your terminal

Mac: Press ⌘ Space, type Terminal, press Enter.

Windows: Press ⊞ Win, type PowerShell, press Enter.

Install Claude Code

Copy the command for your computer, paste it into your terminal, and press Enter.

Mac or Linux (Terminal):

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

The installer shows no progress while it downloads, so it may look frozen for a minute. That's normal. Wait until you see the prompt again.

When it finishes, close your terminal window and open a new one, then check that it worked:

claude --version

You should see a version number. You're ready for Step 3. If you see "command not found" or "not recognized," make sure you opened a new terminal window, then ask your instructor.

Step 3

Set Your Key and Start Claude Code

Your instructor will give you an API key. This is what allows Claude Code to connect to Anthropic's AI — without it, the tool won't work.

  1. 1
    Get your key from your instructor

    It looks like: sk-ant-api03-…

  2. 2
    Set your key in the terminal

    Copy the command for your computer, replace your-key-here with your key (keep the single quotes around it), and press Enter. Nothing visible happens — that's normal.

    Mac or Linux (Terminal):

    export ANTHROPIC_API_KEY='your-key-here'

    Windows (PowerShell):

    $env:ANTHROPIC_API_KEY = 'your-key-here'
  3. 3
    Create a project folder

    In the same terminal window (so your key is still set), make a folder for your website and move into it:

    mkdir my-website cd my-website
  4. 4
    Start Claude Code in your project
    claude

    Claude Code notices your key and asks whether you want to use it. Choose Yes. It may also ask a couple of quick setup questions — the default answers are fine.

  5. ✓
    You're connected to Claude!

    You should see the Claude Code prompt. Type /help to explore, or keep reading to start building.

⏱ Your key only lasts for this terminal window. If you close it or open a new window, run the command from step 2 again before starting claude. If Claude Code asks you to log in through a browser, that's the sign you need to set the key again.
🔒 Keep your key private. Only ever paste it into the terminal command above. Never paste it into a file, a chat message, or a screenshot — and never put it anywhere in your project folder, because that folder gets uploaded to a public website in Step 5. If you think it was exposed, let your instructor know immediately.
Step 4

Build Your Website

This is the fun part. You describe what you want in plain English — Claude Code writes the code, creates the files, and you preview the result in your browser.

  1. 1
    Describe your site — try something like this

    Type this at the Claude Code prompt from Step 3. (Closed that window? Open a new one, set your key again, then run cd my-website and claude.)

    Create a personal website for me. My name is [Your Name]. Include an About Me section, a section for my interests or hobbies, and a contact link. Use a modern, clean design. Plain HTML and CSS, one page. Tell me your plan before you start.

    Customize the prompt with your own details. Remember that your site will be public: for the contact link, use something like a LinkedIn profile or a school or work email, and leave out personal phone numbers, home addresses, and private email addresses.

  2. 2
    Preview your site

    Find the index.html file Claude created in your my-website folder. Open a second terminal window (leave Claude Code running in the first), go to your folder with cd my-website, and run the command for your computer:

    Mac:

    open index.html

    Windows (PowerShell):

    start index.html

    Or skip the terminal: find the file in Finder or File Explorer and double-click it (on a Mac you can also right-click → Open With → your browser).

  3. 3
    Keep refining with more prompts
    Change the color scheme to something warmer. Add a photo placeholder at the top. Make the navigation stick when I scroll.

    Reload your browser after each change to see the result. Keep going until you're happy.

Step 5

Publish to GitHub Pages

Upload your site to GitHub in your web browser to get a live URL — no extra software needed.

  1. 1
    Create a repository on GitHub

    Go to github.com/new. Name it exactly: your-user-name.github.io (use your actual GitHub username). Set it to Public and click Create repository.

  2. 2
    Choose to upload files

    On your new, empty repository page, click the uploading an existing file link.

  3. 3
    Drag in your website files

    Open your my-website folder in Finder or File Explorer. Select everything inside it and drag those files into the browser window — drag the contents, not the folder itself. index.html must sit at the top level of the repository, not inside a folder.

  4. 4
    Click Commit changes

    The green button at the bottom of the page. This saves your files to GitHub.

  5. 5
    Wait 1–2 minutes, then visit your URL
    https://your-user-name.github.io

    Not live yet? Click the Actions tab on your repository to watch it publish, or check Settings → Pages.

  6. ✓
    Your site is live!

    Share the URL with anyone. It's on the internet for free, and yours to keep.

🔄 Updating your site later Make your changes with Claude Code, then repeat steps 2–4: open your repository, click Add file → Upload files, and drag in the changed files. Files with the same name are replaced. Give it a minute or two, then reload your site.
Optional: publish with git instead (for people already comfortable with git)

Use this instead of steps 2–4 above, not after them — your repository must still be empty. You'll need git installed. In your my-website folder, run:

git init git add . git commit -m "My first website" git branch -M main git remote add origin https://github.com/your-user-name/your-user-name.github.io.git git push -u origin main

Replace both instances of your-user-name with your GitHub username. When GitHub asks you to sign in, your regular GitHub password won't work: use the browser sign-in window if one opens, or a personal access token. If you get stuck, use the upload steps above instead.

To update later: git add ., git commit -m "Update", git push.
